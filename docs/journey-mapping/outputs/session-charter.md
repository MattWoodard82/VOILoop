# VOILoop Journey Mapping Workshop — Session Charter

**Date:** August 24, 2026  
**Participants:** Matt (Founder), Heather (Wellness Director SME)  
**Facilitator:** AI-assisted workshop model

## Primary Objective
Produce high-quality, evidence-labeled, actionable journey maps for four personas (Participant, Wellness Director, Admin, Exec) to guide UX refactors and roadmap prioritization.

## Scope Decisions (Phase 0 — Confirmed)

### Personas
1. **Participant** — Employees in employer-sponsored wellness programs (mix of health-motivated and auto-enrolled)
2. **Wellness Director** — Outcomes-focused wellness professional managing day-to-day program (not HR/benefits governance, which rolls into Exec)
3. **Admin** — SKIPPED for now (can be addressed in follow-up workshop)
4. **Exec** — Employer-side C-suite; sees aggregated data only, no participant-level visibility

### Mapping Approach
- **Both as-is (current reality) and future-state (desired future) in parallel**
- Ground everything in evidence, not preferences
- Surface contradictions and gaps immediately
- Validate drafts live with probing questions

### Key Decisions
- **As-is focus:** Grounded in pilot experience + anticipated friction, not theoretical
- **Future-state co-creation:** Define desired behavior and UX alongside current-state mapping
- **Evidence bar:** Concrete examples, user data, pilot observations—not assumptions
